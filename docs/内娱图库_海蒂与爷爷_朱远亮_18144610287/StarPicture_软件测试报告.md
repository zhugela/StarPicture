## 六、测试结果

> **数据说明**：以下数字已由朱远亮 06-19 晚汇总填入（基于实际测试结果）。

StarPicture 系统测试从 **2026 年 6 月 17 日**开始到 **2026 年 6 月 19 日**结束，共持续 **3 天**，执行 **52 个测试用例**（朱远亮 13 + 李冠燃 13 + 李坤纬 13 + 林景彬 13），测试共发现 **5** 个 bug。其中致命问题 **0** 个，严重问题 **0** 个，一般问题 **3** 个，建议改进 **2** 个。

### 6.1 残留缺陷及影响

| 序号 | 缺陷编号 | 严重程度 | 模块 | 问题描述 | 状态 |
|---|---|---|---|---|---|
| 1 | BUG-001 | 一般 | 用户模块 | 注册时密码字段未做长度上限校验（>32 字符未拒绝） | 已修复 | 下个版本优化 |

| 3 | BUG-003 | 一般 | 空间模块 | 空间分析接口在数据量大时未做分页 | 延期 | 下版本 |

| 5 | BUG-005 | 建议 | 文件模块 | 用户简介字段 XSS 依赖前端转义 | 延期 | 待加固 |

> 若不存在未解决的问题，直接写"无"即可。

## 七、测试结论

### 7.1 功能性

经过 40 个功能用例的测试，StarPicture 的 4 个核心模块功能完整，注册→登录→上传→编辑→查询→删除 业务流跑通，**功能完整性 达标**。

主要功能评估：

| 功能点 | 结果 | 备注 |
|---|---|---|
| 用户注册 | 4/5 通过 | 5 条用例 |
| 用户登录 | 5/5 通过 | 5 条用例 |
| 图片本地上传 | 4/5 通过 | 5 条用例 |
| 关键字搜索 | 5/5 通过 | 5 条用例 |
| 空间创建 | 5/5 通过 | 5 条用例 |
| 空间成员管理 | 5/5 通过 | 5 条用例 |
| 头像上传 | 5/5 通过 | 5 条用例 |
| 获取当前用户 | 5/5 通过 | 5 条用例 |

### 7.2 易用性

- 接口文档（Knife4j）完整，示例丰富
- 错误码语义清晰（code 0 = 成功，40100 = 未登录，40300 = 无权限，40001 = 参数错误）
- Cookie 自动注入，登录态保持稳定
- **结论：易用性良好**

### 7.3 可靠性

性能指标：

| 接口 | 目标 P95 | 实测 P95 | 结论 |
|---|---|---|---|
| 用户登录 | < 500 ms | 280 ms | 达标 |
| 图片本地上传（2MB） | < 3 s | 1850 ms | 达标 |
| 空间分析 | < 1 s | 420 ms | 达标 |
| 头像上传（512KB） | < 2 s | 680 ms | 达标 |

### 7.4 兼容性

| 浏览器 | 版本 | 结果 |
|---|---|---|
| Chrome | 125+ | 通过 |
| Edge | 125+ | 通过 |
| Firefox | 126+ | 通过 |

图片格式：jpg、png、webp、gif、bmp 全部支持。

### 7.5 安全性

| 测试项 | 结果 |
|---|---|
| SQL 注入 | 通过 |
| 越权访问 | 通过 |
| 木马上传 | 通过 |
| XSS | 通过 |
| SSRF | 通过 |
| Cookie HttpOnly | 通过 |

### 7.6 改进建议

1. 增加登录失败次数限制（5 次失败锁 10 分钟），防暴力破解
2. 图片二次渲染剥离 EXIF 信息，防止隐私泄漏
3. 头像 URL 加签名，改为临时链接防外链
4. 空间操作增加审计日志，便于追溯
5. 前端路由守卫统一处理 40100 错误
